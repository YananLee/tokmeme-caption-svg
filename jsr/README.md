# tokmeme-caption-svg

A small local SVG generator associated with [TokMeme](https://tokmeme.com/). It does not call the product website or export service.

Install: `npx jsr add @yananlee/tokmeme-caption-svg`. Import `renderMeme` from `@yananlee/tokmeme-caption-svg` and render SVG using your own captions.
